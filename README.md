# Blutti Frutti

Napi zsé-figyelő app iPhone-ra, lélekcsiholó kerettel és vitaminnaplóval. Nyisd meg Safariban, Megosztás → Főképernyőhöz adás.

Fejlesztőknek / Claude Code-nak: **olvasd el a [CLAUDE.md](CLAUDE.md)-t** – ott van a teljes projekt-átadó (felépítés, kiadás, állapot). Forrás: `src/blutti-frutti.html`, build: `python3 build.py`, teszt: `node tools/test.js`.
